Sahna Node 01

Инженерный прототип · идёт проверка

О проекте

Sahna Node 01 — разрабатываемый сетевой шлюз для преобразования Art-Net в один физический выход DMX512. Проект рассчитан на сценическое световое оборудование и тестируется как компактная однопортовая нода.

Текущая аппаратная платформа разработки — WT32-ETH01 на ESP32 с Ethernet PHY LAN8720. Программная реализация Art-Net 4 и физический DMX-тракт проходят проверку; продукт пока не выпущен.

Функции текущей версии

Один DMX-выход

Один физический выход DMX512 и один назначаемый DMX-универс.

Art-Net по Ethernet

Одноадресный сетевой шлюз на базе WT32-ETH01. Совместимость проверяется в ходе разработки.

Без RDM

Двусторонний обмен RDM в этой версии не реализуется. Направление DMX — только на выход.

Профиль протокола

В прошивке прототипа реализуются сетевой запуск ноды и обработка основных сообщений Art-Net для одного выходного порта.

  • Обнаружение и объявление ноды: ArtPoll / ArtPollReply.
  • Выходные данные DMX: ArtDmx, с поддержкой ArtSync и ArtNzs.
  • Управление настройками порта и IP: ArtAddress и ArtIpProg.
  • Сетевое объединение источников реализовано в прошивке; совместимость и поведение проверяются.

English product summary

Sahna Node 01 is a single-output Art-Net to DMX512 gateway in engineering prototype development by Sahna Lab, an individual lighting-control and electronics development project based in Kazakhstan.

The current development platform is WT32-ETH01 (ESP32 with LAN8720 Ethernet PHY). The planned product receives one Art-Net universe, has no physical DMX input and one physical DMX512 output. RDM is not supported. Art-Net 4 implementation and hardware interoperability are still under validation. No certification or commercial release is claimed. An ESTA Manufacturer ID has been requested separately; an Art-Net OEM Code has not yet been assigned.
